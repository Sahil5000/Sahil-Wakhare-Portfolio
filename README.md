# Sahil Wakhare | Portfolio

Personal portfolio of **Sahil Namdev Wakhare**, a Software Developer focused on AI and Cloud.

## Sections

- Hero with typing animation and tech badges
- Professional Bio
- What I Do (Generative AI, Cloud & DevOps, Full-Stack, AI-Assisted Coding)
- Technical Expertise (animated skill bars)
- Work History
- Certifications (click a card to view the certificate PDF)
- Projects
- Contact (phone, email, WhatsApp, LinkedIn)

## Tech

Plain HTML, CSS and JavaScript. No build step.

- [Poppins](https://fonts.google.com/specimen/Poppins) font
- [Font Awesome 4.7](https://fontawesome.com/v4/icons/) icons
- [AOS](https://michalsnik.github.io/aos/) scroll animations

## Editing content

All text lives in [`data.js`](data.js): name, tagline, bio, skills, experience, certifications, projects and contact details. Edit that file and refresh the page.

## Run locally

Open `index.html` in a browser.

## Structure

```
index.html          Page layout
style.css           Styles and responsive rules
script.js           Renders content from data.js and adds interactions
data.js             All portfolio content
assets/
  images/           Profile photo and hero background
  certificates/     Certificate PDFs
  download/         Resume PDF
```
